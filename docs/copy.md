# Wayward copy

Every player-facing string in the addon, by file and line, for auditing. Generated by `tools/extract_copy.py`; edit the Lua file the line points to, then run it again. A sentence built from several pieces appears as its pieces, in order. `%s` and `%d` are filled in at run time; `|cffRRGGBB` ... `|r` colours a stretch of text.
